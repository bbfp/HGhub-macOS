# HGhub macOS 自用版

适用于 Apple Silicon（M 芯片）Mac。App 已内置视频合并工具，使用时不需要安装 Rust、Node 或 FFmpeg。

## 打开

打开交付目录中的 `HGhub.app`，也可以打开 `.dmg` 后把 App 拖到你想保存的位置。更新时先退出旧 App，再替换 App 文件。

本版使用本机临时签名，没有 Apple 公证。如果系统阻止首次启动，在确认文件来自本次构建后，右键 App，选择“打开”；系统仍阻止时，到“系统设置 → 隐私与安全性”查看“仍要打开”。

每次启动 macOS App 都会先进入“我的”，并默认静音。右上角喇叭按钮可以在本次运行中开启或关闭声音；进入首页后视频停在封面，点击播放器上的播放按钮才会开始播放。

启动时 App 会并行检测已配置的 API 域名，按有效响应速度排序；后续请求先使用最快的域名，失败后依次切换备用域名。

## 下载与播放

1. 在短剧播放页打开“选集”，点“下载”。进入下载选择后默认全选；可以用“清空”后再单选，也可以用“整剧全选”。
2. “整剧全选”只负责选中，点“下载所选 N 集”才会加入任务。
3. 默认下载地址在“我的 → 下载地址 → 更改”设置；“下载”页也会显示这个地址。选集面板的“本次换地址”只改变当前任务，不会修改默认地址。以上设置无需登录。
4. macOS 侧栏的“下载”页按短剧归类查看任务，可展开或折叠，支持暂停、继续、取消或重试。取消会保留已有文件和可复用的片段。
5. macOS 侧栏的“我下载的”页按本地目录动态加载已完成短剧，进入列表后检查远端新增集数；更新只提示，不会自动下载。可以点“下载全部更新”，或勾选短剧后点“下载所选”。按钮会同时显示短剧数和新增总集数，点击后直接使用已检查结果入队，并立即切到“下载”页刷新。
6. 已完成的集数可点“离线播放”。退出后，正在下载和等待中的任务会在下次启动继续；手动暂停的任务保持暂停。

首页、分类、排行榜、搜索和“我的”中的短剧卡片会显示“已下载”标识。标识只代表至少有一集 MP4 和校验回执已经完成；等待、暂停、失败或未完成的集数不会提前显示为已下载。进入选集面板后，每个已完成集数会单独显示对勾。

“下载”页顶部会显示未完成短剧数、未完成集数，以及下载中、等待、暂停和失败/重试的任务数量。点击“全部”或任一状态即可筛选短剧和集数，再次点击当前状态可恢复全部。侧栏“下载”角标按未完成集数显示。失败或取消的任务可单条删除，也可以一键删除全部失败/取消记录；删除只清理任务记录和临时片段，已完成 MP4 会保留。已完成任务还可以点“打开所在文件夹”，在 Finder 中定位对应 MP4。

在“下载”页的“下载并发”中修改三个数字，再点“保存并发设置”：

- 全局同时下载任务数，默认 **5**。一个任务对应一集。
- 同一部剧同时下载集数，默认 **3**，也计入上述全局任务数。
- 每集同时下载分片数，默认 **4**。

默认满载最多同时下载 `5 × 4 = 20` 个分片；只有一部剧时，最多同时下载 3 集。全局任务数和同剧集数可设为 1–32，每集分片数可设为 1–16。保存后自动生效并在重启后保留；降低上限时，已有任务和分片先完成，随后按新上限补充，不会重下已完成的片段。旧版设置没有这三个数字时，自动使用 5 / 3 / 4。

视频保存为 MP4。新下载目录为 `drama-ID-名字/episodes/001.mp4`；标题无法使用时退回 `drama-ID`。旧版本的 `drama-ID` 下载仍可读取和播放。

## 备用域名

在“我的 → 网络设置 · 备用域名”中编辑，每行一个域名，点“保存域名”。无需登录。默认包含原主域名及以下三个镜像：

- `olfs.gitiecgad.cc`
- `y6wb.gitiecgad.cc`
- `omqefh.gitiecgad.cc`

 “检测可用性”会并行请求视频列表，并按响应速度显示结果。启动时也会自动执行同样的检测；公开内容遇到连接失败、超时或 HTTP 5xx 时自动尝试下一个域名。手动保存的域名列表会保留，自动测速排序只保留到本次运行结束。

登录、注册、带登录状态的请求和下载地址刷新也使用这组已配置域名。连接故障会逐个换源；普通写操作在请求结果不明确时停止重发并提示“结果未知”，避免重复评论、点赞等操作。HTTP 业务错误会直接显示。媒体 CDN 地址保持上游返回的原地址，只使用当前站点作为 Referer；镜像能决定接口及媒体、封面和密钥地址，请只填写自己认可的镜像。

## 文件与更新

默认视频目录是 `~/Movies/HGhub`（界面会显示实际位置）。每部短剧使用稳定的编号建目录：`drama-编号/episodes/001.mp4`。同目录的 `001.json` 保存该集的信息和文件校验值；封面保存在短剧目录及 App 图片缓存中。

任务、目录设置和图片缓存默认位于 `~/Library/Application Support/com.hghub.huangguo/`。更新 App 时保留这个目录和下载目录。数据格式从本版开始标为 v1；后续版本须继续读取。当前验证覆盖了 v1 的读取和未知字段保留，未来版本尚未实现，也尚未验证跨版本升级。

下载索引位于同一数据目录的 `downloads/library-index.json`，schema 为 1。它由已完成且校验通过的任务增量维护；首次运行新版本时会从现有任务和回执重建一次。列表页只批量查询当前可见的短剧 ID，不逐卡扫描文件。外层卡片仍需在线加载剧集详情；“我下载的”继续提供本地 MP4 播放。

封面会保存在磁盘，同一资源再次打开会读缓存。实际打开速度取决于本机磁盘和页面数据；当前没有给“秒开”做性能承诺。

## 当前验证范围

本地测试已覆盖下载、有限并行、暂停与取消、失败重试、强制退出后的续传、地址过期刷新、图片缓存、MP4 合并和解码。macOS 窗口中已验证本地视频播放与跳转、通过本地代理的 HLS 播放、目录选择，以及更换目录后旧文件的播放。测试视频均为自生成样本。

原主域名在本机曾连接失败，访问情况可能随网络而变化；本轮使用 App 的 Rust 网络层验证了三个镜像的真实视频列表，以及真实播放地址、HLS 清单和视频分片。另已完成一集真实视频的 186 个片段下载、MP4 合并和全量音视频解码验证。账号操作保留，本轮没有登录账号、注册或提交内容。

若首页没有内容，先到“我的 → 网络设置 · 备用域名”点“检测可用性”，补充或调整可用域名后保存，再返回首页重试。若所有域名都连接失败，再检查代理节点和网络规则。程序不修改系统代理或 DNS。下载任务失败时会显示具体错误，可点“重试”。

若整个任务记录文件损坏，本版会保留损坏文件并显示提示，视频和每集信息文件不会删除；列表暂时无法显示这些旧任务，需要根据保留文件恢复记录。本版尚未提供自动重建列表。

## 开发者入口

本仓库的工具链和下载缓存位于 `.local/`。重新构建：`pnpm macos:build`。运行 Rust 检查：`node scripts/macos.mjs cargo test --locked --offline --lib`。完整构建与数据格式说明见 [BUILD.md](BUILD.md)。
