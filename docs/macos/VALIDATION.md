# macOS 验证范围

2026-11-07，在 Apple Silicon macOS 上完成以下本机验证。结果只覆盖列出的场景，不代表其他 Mac、Windows/Android 或所有上游站点状态。

| 检查 | 结果 |
| --- | --- |
| Rust 本地回归 | 41 项通过，6 项外网/人工用例默认忽略 |
| 前端与平台 | TypeScript/Vite 构建、2 项平台测试通过 |
| Rust 静态检查 | 全 targets/features 的 Clippy 通过，警告作为错误 |
| 三层并发 | 本地受控请求观测到 5 个活动任务、同剧最多 3 集、20 个分片请求；自定义分片 1、2 生效 |
| 运行中降限 | 已运行任务不中断，后续任务等待容量释放；合成视频最终解码通过 |
| 设置 | 旧设置默认值、持久化、重启、未知字段保留、目录与并发同时保存、坏值和未来版本保护均有回归 |
| macOS 界面 | 独立 WKWebView 测试验证默认 5/3/4、拒绝 0、草稿跨轮询保留、保存 7/2/6、改目录保留并发、重启读回；保存后旧轮询晚到不覆盖新值 |
| 下载可靠性 | AES-128、TS/fMP4、暂停/取消/重试、地址刷新、损坏分片重下、强退续传、MP4 合并和解码通过 |
| 封面缓存 | 并发只请求一次，清空内存后读磁盘，签名变化可复用 |
| 包 | arm64 App、临时签名与 DMG 完整性检查通过，内置 FFmpeg 可执行 |

上述并发测试采用受控本地服务，未额外对真实源站进行并发压力测试。过去已验证三个默认镜像的视频列表、播放链路和一集真实视频的下载与全量解码，但网络结果会变化，不能据此保证永久可用。账号登录/注册/评论/点赞没有使用真实凭据做本轮验收。

普通构建与独立测试版的数据隔离；当前下载任务不作为测试样本。测试源码在 `src-tauri/src/downloads/tests.rs`、`net_tests.rs`、`network_tests.rs` 和 `src-tauri/tests/`，可按 BUILD.md 复现。

尚未新增验收：DMG 挂载安装、其他机器、非 macOS 运行、未来版本升级。整个任务文件损坏时会保留数据，但自动重建下载列表尚未实现。App 采用临时签名，无 Apple 公证。

源码复核指出的保存/轮询竞态已先用隔离 WKWebView 复现，再修复并通过相同回归。公开源码目录也单独安装了锁定依赖并通过上述测试；沿用了本地 Rust/Cargo 缓存和已构建的 FFmpeg，没有把这些工具放进 Git。首次全量复测有一项本地 HTTP fixture 失败，定位中发现 Darwin 接受的 socket 会继承非阻塞标志；fixture 已显式切回阻塞读取，修正后全量 41 项通过。原失败没有被计作通过。
